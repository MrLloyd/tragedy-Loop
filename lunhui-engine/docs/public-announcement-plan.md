# v2 公开日志与视图

此页替代旧 trace 投影接口计划。v2 的公开事实保存于 GameState.publicLog，使用独立递增 sequence；原始 trace 保存私密执行细节，绝不直接对玩家发送。

当前公开日志覆盖阶段进入、事件发生／未发生／无现象、翻牌、指示物变化（含版图、行动牌和护卫消耗）、移动、死亡、复活、移除、明确身份公开、友好拒绝、EX和世界移动、信息能力，以及剧作家获得绝望牌的公告。主人公死亡／失败在最外层步骤必须后续收尾后公告；同时成立只公告死亡。仍不承诺旧版公告 DTO 或游标接口。

view(seat) 白名单提供公开事件表的日期和公开名称，不返回实际事件标识、当事人或私密规则选项；只显示本席行动牌正面与本席待选项，行动牌公开后才显示其他席位牌面。LL 字母仅返回给所属主人公。诅咒、领地和EX牌存在性公开；EX牌不暴露背后的规则编码。未结束的必须后续中不提前公开最终胜负 result。

界面可以用 publicLog.sequence 去重或增量显示，但当前传输返回完整公开快照。LocalTransport 不是远端鉴权服务，也没有 announcementsFor 或 getAnnouncements 接口。

不得从内部来源 ID、未公开身份或原始状态差异自行生成客户端公告。游戏结束界面、中文阶段显示优化、断线增量补发协议和公告全面组合验收均不在当前已有验证承诺内。
